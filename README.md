# Tolga Temiz Academic Website

This is the updated publication-ready website package.

## Included

- `index.html` — website content
- `style.css` — styling and responsive layout
- `portrait.jpg` — optimized professional photograph
- `Tolga-Temiz-CV.pdf` — compiled CV

## One item still needed

Before publishing, add your preferred MSU email address in the Contact section of
`index.html`. Search for the sentence “Add your preferred MSU email address here.”
and replace that paragraph with a mail link such as:

    <p><a href="mailto:name@msu.edu">name@msu.edu</a></p>

## Preview

Double-click `index.html` to view the site locally.

## Publish with GitHub Pages

1. Create a free GitHub account.
2. Create a public repository named `YOUR-USERNAME.github.io`.
3. Upload the four files in this folder.
4. Visit `https://YOUR-USERNAME.github.io` after GitHub finishes publishing.
